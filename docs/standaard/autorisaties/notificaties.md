# Autorisaties kanalen

## Autorisatiecomponent (AC)

Kanalen worden typisch per component gedefinieerd. Producers versturen berichten op bepaalde kanalen, consumers ontvangen deze. Consumers abonneren zich via de Notificaties API.

Hieronder staan de kanalen beschreven die door deze component gebruikt worden, met de kenmerken bij elk bericht.
